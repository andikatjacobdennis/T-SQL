    011. T-SQL Practice Problems

    Basic SELECT Queries (Problems 1-20)

    1. Select all columns from the Employees table
    2. Select only FirstName and LastName from Employees
    3. Select distinct departments from the Employees table
    4. Select employees hired in the last 30 days
    5. Select employees with salaries between 50000 and 80000
    6. Select employees whose last names start with 'S'
    7. Select employees ordered by hire date (newest first)
    8. Select the top 5 highest paid employees
    9. Count the number of employees in each department
    10. Calculate the average salary by job title
    11. Find employees with NULL values in the manager_id column
    12. Concatenate first and last names with a space in between
    13. Select employees hired in 2023
    14. Calculate the length of service for each employee in years
    15. Find employees whose email contains 'example.com'
    16. Select products with prices above the average price
    17. Find orders placed on weekends
    18. Calculate total sales by month
    19. Find duplicate email addresses in the Employees table
    20. Select customers who haven't placed any orders
