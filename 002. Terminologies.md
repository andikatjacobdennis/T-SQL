## 002. Terminologies (Basic to Advanced)

---

### 🔹 **Basic Concepts**

* **Data**

  * Raw facts or values stored in a database (e.g., numbers, text, dates).

* **Table**

  * A collection of rows and columns that stores data about a specific subject, like Customers or Orders.

* **Column (Field)**

  * A named attribute or data category within a table (e.g., Name, Age).

* **Row (Record)**

  * A single entry or instance in a table, representing a single item or entity.

* **Relational Database**

  * A database that organizes data into tables which are related to each other via keys.

* **RDBMS (Relational Database Management System)**

  * Software that manages relational databases and allows users to interact with the data using SQL (e.g., MS SQL Server, MySQL, PostgreSQL).

* **SQL (Structured Query Language)**

  * The standard language for managing and manipulating relational databases using commands like `SELECT`, `INSERT`, `UPDATE`, and `DELETE`.

---

### 🔹 **Intermediate Concepts**

* **Primary Key**

  * A column (or set of columns) that uniquely identifies each row in a table.

* **Foreign Key**

  * A column that links one table to the primary key of another, establishing a relationship between tables.

* **Normalization**

  * The process of organizing data to minimize redundancy and improve data integrity.

* **Constraints**

  * Rules enforced on columns to ensure valid data (e.g., `NOT NULL`, `UNIQUE`, `CHECK`, `DEFAULT`).

* **Query**

  * A request for data or action performed on a database (e.g., using `SELECT` to retrieve rows).

* **Index**

  * A performance-boosting structure that allows faster retrieval of rows based on column values.

* **View**

  * A virtual table based on a `SELECT` query; used to simplify access or limit exposure to data.

* **Transaction**

  * A sequence of operations executed as a single unit of work, ensuring **ACID** properties (Atomicity, Consistency, Isolation, Durability).

---

### 🔹 **Advanced Concepts**

* **Stored Procedure**

  * A saved block of T-SQL code that performs operations in the database; reusable and efficient.

* **Function (UDF – User Defined Function)**

  * A reusable block of T-SQL that returns a value or table and can be used in queries.

* **Trigger**

  * A special type of stored procedure that automatically runs in response to events like `INSERT`, `UPDATE`, or `DELETE`.

* **T-SQL (Transact-SQL)**

  * Microsoft's extension to SQL that adds procedural logic (e.g., `IF`, `WHILE`, error handling) and system-level functions.

* **MS SQL Server (Microsoft SQL Server)**

  * A robust RDBMS developed by Microsoft that uses T-SQL and supports enterprise-level features like backups, replication, and security.

* **Cursor**

  * A database object used to retrieve rows one at a time; used when row-by-row processing is needed.

* **Common Table Expression (CTE)**

  * A temporary result set that can be referenced within a `SELECT`, `INSERT`, `UPDATE`, or `DELETE` query.

* **Window Function**

  * A function that performs calculations across a set of rows related to the current row (e.g., `ROW_NUMBER()`, `RANK()`).

* **MERGE Statement**

  * A T-SQL statement that allows conditional `INSERT`, `UPDATE`, or `DELETE` actions in a single statement based on data comparison.

* **JSON / XML Support**

  * Modern T-SQL features to parse and store semi-structured data formats like JSON and XML.

* **Graph Database Features**

  * SQL Server’s advanced capabilities to model and query data as nodes and edges (useful for social networks, hierarchies).
